# Platform Documentation References

Authoritative references for Android and Samsung platform behaviour.
Consult them when implementing platform-specific features, debugging
device quirks, or aligning with OEM conventions.

| Site | URL | Scope |
|---|---|---|
| Android Developers Blog | <https://android-developers.googleblog.com/> | Feature announcements, best practices, API deep-dives |
| Android Open Source Project | <https://source.android.com/docs/> | AOSP internals, HAL, system architecture |
| Android Developers | <https://developer.android.com/> | Official SDK/API docs, Jetpack libraries, Material Design |
| Android Developers — Quality | <https://developer.android.com/quality> | App quality guidelines, core app quality, Play Store requirements |
| Android Developers — Performance | <https://developer.android.com/topic/performance/> | Performance best practices, memory, battery, network, profiling |
| Samsung Developers | <https://developer.samsung.com/> | One UI behaviour, Samsung-specific APIs, device testing guides |
