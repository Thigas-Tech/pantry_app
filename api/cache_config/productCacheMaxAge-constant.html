productCacheMaxAge top-level constant

Duration const productCacheMaxAge

Maximum age of an API-fetched cached product before it is flushed from the device. Two months.

Products whose lastSynced timestamp is older than this are removed by DatabaseHelper.flushExpiredCachedProducts and re-fetched on the next access or background refresh.

Implementation

const Duration productCacheMaxAge = Duration(days: 60);
