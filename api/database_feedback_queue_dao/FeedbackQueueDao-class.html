FeedbackQueueDao

FeedbackQueueDao class

DAO for the feedback_queue table.

Stores issues that could not be submitted immediately (e.g. because the device was offline). When connectivity is restored, the pending rows are flushed to the GitHub Issues API by GithubIssueService.flushQueue.
