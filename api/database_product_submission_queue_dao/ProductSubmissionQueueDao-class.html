ProductSubmissionQueueDao

ProductSubmissionQueueDao class

Data-access layer for the product_submission_queue table.

This table holds barcodes of products that the user attempted to submit to Open Food Facts while offline. Rows are inserted when a submission fails (network error) and removed when the submission succeeds. A startup task and connectivity-change listener process the queue.
