The normalized numeric quantity in g or ml (e.g. 500 for "500 ml", 450 for "3 x 150 g").

Sourced from the OFF API product_quantity field. This is the total quantity, not the per-unit value for multi-pack items. For pre-fill, QuantityParser extracts the per-unit value from quantity instead.
