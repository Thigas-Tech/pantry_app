RecipeCacheEntry

RecipeCacheEntry class abstract

Firestore document for the recipe_cache/{recipeId} collection.

Stores an anonymized, cross-device shareable snapshot of a user's recipe. No PII (user ID, device ID, local file paths) is stored.

recipeId is a SHA-256 hex hash derived from the original recipe's name and createdAt, ensuring deterministic, collision-resistant IDs that cannot be traced back to the local SQLite database.
