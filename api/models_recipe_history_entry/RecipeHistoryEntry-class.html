RecipeHistoryEntry

RecipeHistoryEntry class abstract

An immutable record of a recipe being cooked (marked as "made").

Each RecipeHistoryEntry logs when a user cooked a recipe, the cost at that time, and a snapshot of the ingredients that were used. Once created, this entry is never modified — it serves as an audit log.

Identity

  • id is the auto-generated primary key from the recipe_history table.
  • recipeId is the foreign key referencing the recipes table. Note that if the recipe is later deleted, this entry survives so stats remain accurate.
