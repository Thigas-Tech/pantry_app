AuthServiceProvider authServiceProvider
final

Provides the singleton AuthService instance.

When FIREBASE_ENABLED=true, this creates a FirebaseAuthService backed by FirebaseAuth.instance. Anonymous sign-in happens in main() before the widget tree mounts, so the service is ready from the first frame.

Lifetime

Plain keep-alive provider — the service lives for the entire app session. This matches the pattern used by the firebase cache provider.

Implementation

@ProviderFor(authService)
final authServiceProvider = AuthServiceProvider._();
