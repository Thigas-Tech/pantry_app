ScannerCamera

ScannerCamera class

Notifier that manages the scanner camera lifecycle and scan resolution.

Owns the MobileScannerController (created with autoStart false), tracks camera streaming state, handles permission requests, and resolves barcodes/PLU codes via productRepositoryProvider.
