StatsProvider statsProvider
final

Aggregated statistics for the active pantry inventory.

Computed from SQL aggregation queries in ProductDao and InventoryDao. Depends on activeInventoryProvider so it refreshes when the user switches pantries. Auto-disposes to release memory when leaving the Stats tab.
