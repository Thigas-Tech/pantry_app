ThemeModeNotifier

ThemeModeNotifier class

A notifier that holds the current ThemeModeOption and persists it to SharedPreferences under the theme_mode key.

Loads the persisted mode in build so no placeholder value flashes. Used by themeModeProvider so that any widget can read or change the theme mode.
