UiFlags

UiFlags class

Transient one-shot UI flags persisted to SharedPreferences.

Unlike Settings (user preferences), these are cross-cutting one-shot flags read/written ad-hoc across the shell, settings, and startup paths. Routing them through UiFlagsNotifier gives them a single owner with typed getters and setters.
