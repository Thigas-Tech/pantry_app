String detectLocaleCurrency()

Detects the likely currency code from the device locale.

Uses Platform.localeName and a curated mapping of country codes to ISO 4217 currency codes. Falls back to 'USD'.

Implementation

String detectLocaleCurrency() {
  try {
    final locale = Platform.localeName;
    final code = locale.contains('_') ? locale.split('_').last : '';
    return switch (code.toUpperCase()) {
      'BR' => 'BRL',
      'US' => 'USD',
