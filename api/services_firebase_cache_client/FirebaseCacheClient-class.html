FirebaseCacheClient

FirebaseCacheClient class

Low-level Firestore client for product and produce caches.

Wraps two Firestore collections:

  • produce_cache/{name} -- USDA produce data (ProduceCacheEntry)
  • product_cache/{barcode} -- OFF barcoded product data (ProductCacheEntry)

Graceful degradation

When isAvailable is false, all get* methods return null and all set* methods return false. This allows the app to function without Firebase (e.g. development builds, missing google-services.json).
