FirestoreClient

FirestoreClient class abstract

Minimal Firestore-like interface that FirebaseCacheClient depends on.

Declared as an abstract class so the client avoids a hard import of cloud_firestore in test code. In production this is backed by a FirebaseFirestore instance; in tests by mocktail mocks.
