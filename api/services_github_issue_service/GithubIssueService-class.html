GithubIssueService

GithubIssueService class

Submits feedback as GitHub Issues and manages an offline queue.

On platforms that support HTTP (Android, iOS, desktop), issues are posted to the GitHub Issues API with the developer's PAT. When the device is offline the issue is stored in the feedback_queue SQLite table and flushed automatically when connectivity is restored.

On web the service falls back to a mailto: URI because sqflite and direct HTTP calls to authenticated GitHub endpoints are not practical.
