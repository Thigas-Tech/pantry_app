Creates an OffAdapter.

If useStaging is true, API calls target the OFF staging server (world.openfoodfacts.net); otherwise they target production (world.openfoodfacts.org).

Each on* parameter overrides the corresponding SDK static call for testing. When omitted the real SDK method is used.
