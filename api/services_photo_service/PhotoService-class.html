PhotoService

PhotoService class

Service for capturing and managing price tag photos.

Photos are captured via the device camera or selected from the gallery, then compressed and saved to a dedicated directory. Each photo is keyed by shopping item ID so it can be located during delete or move-to-inventory operations.
