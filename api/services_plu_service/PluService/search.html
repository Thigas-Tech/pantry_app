Searches the PLU database by name or category.

The search is case-insensitive and matches against both the produce name and its category. Returns an empty list when no entries match.

Implementation

List<PluEntry> search(String query) {
  final lower = query.trim().toLowerCase();
  if (lower.isEmpty) return [];
  return _pluMap.values
      .where(
        (e) =>
            e.name.toLowerCase().contains(lower) ||
            e.category.toLowerCase().contains(lower),
      )
      .toList();
}
