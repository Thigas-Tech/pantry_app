PriceRepository

PriceRepository class

Coordinates price CRUD, formatting, currency conversion, and aggregation.

PriceRepository combines the local PriceDao (via DatabaseHelper) with the CurrencyService for display conversions.

Architecture

Local CRUD methods delegate directly to PriceDao. Formatting and conversion methods use CurrencyService to convert prices to the user's base currency for display.
