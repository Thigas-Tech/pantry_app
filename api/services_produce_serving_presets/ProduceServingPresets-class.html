ProduceServingPresets

ProduceServingPresets class

Serving size presets for common produce items.

Maps produce names to standard serving sizes (Small, Medium, Large) in grams. Used by the weight/unit toggle to provide natural unit options like "1 medium apple (182g)" instead of raw gram input.

When a produce name has no entry, generic sizes are returned: Small=100g, Medium=150g, Large=200g.
