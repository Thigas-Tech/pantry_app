Creates a ProductRepository with the given DatabaseHelper and primary API. An optional fallback API can be provided for future use.

The optional UsdaApiClient is used by addProduceToInventory to fetch nutrition data for produce items from the USDA FoodData Central API when a product is not already cached locally.

The CacheStalenessStore is the single source of truth for cache-staleness tracking, persisting the last inventory refresh in SharedPreferences.
