RecipeService

RecipeService class

Owns all recipe business logic: saving, deleting, cost calculation, shortage checking and the cook transaction.

Kept free of Riverpod so every method is testable with plain dependencies. The active inventory id and base currency are passed in by the caller (which reads them from the providers).
