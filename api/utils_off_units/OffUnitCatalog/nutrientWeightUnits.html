nutrientWeightUnits property

List<String> nutrientWeightUnits
final

Weight unit options offered by the nutrition editor.

These are the units an additional nutrient value can be entered in; Open Food Facts stores weight nutrients per 100 g in grams, and the value is converted back to grams before submission.
