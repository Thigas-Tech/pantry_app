ProgressIndicatorHelper

ProgressIndicatorHelper class

Builds standardized CircularProgressIndicator and LinearProgressIndicator widgets with consistent defaults.

Every method returns a widget that respects the current Material theme colours when no explicit indicator colour is given.

Examples

// Small circular spinner (carousel chips):
ProgressIndicatorHelper.build(size: 16, strokeWidth: 2);

// Full-width linear bar (detail screen loading):
ProgressIndicatorHelper.build(type: ProgressIndicatorType.linear);

// Determinate linear with custom colour:
ProgressIndicatorHelper.build(
  type: ProgressIndicatorType.linear,
  value: 0.45,
  color: Colors.green,
  minHeight: 6,
);
