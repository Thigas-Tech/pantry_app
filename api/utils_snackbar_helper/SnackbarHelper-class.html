SnackbarHelper

SnackbarHelper class

A thin wrapper around ScaffoldMessenger that shows styled snackbars.

Every method shows a floating snackbar with a short duration, rounded corners, and a leading icon that matches the severity level.

See SnackbarHelper.showInfo, SnackbarHelper.showWarning, SnackbarHelper.showError, and SnackbarHelper.showUndo.
