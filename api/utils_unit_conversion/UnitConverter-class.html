UnitConverter

UnitConverter class

Normalizes and converts between compatible measurement units.

Supported unit groups:

  • weight: g, kg, mg, mcg, oz, lb
  • volume: ml, L, tbsp, tsp, cup, fl oz
  • count: pieces
