SearchQueryBar

SearchQueryBar class

A search bar that forwards keystrokes and submissions to the parent.

Owns its own TextEditingController so it can show or hide the clear button as the text changes. Debouncing and the actual search execution live in the SearchPanelController, so this widget is purely presentational and delegates every interaction through onChanged, onSubmitted, and onClear.
