Shows a bottom sheet listing changelog entries since the last seen version.

entries should be the result of ChangelogParser.parse filtered by ChangelogParser.filterUnseen.

Returns true on explicit dismiss (button tap), null on swipe-away. In both cases the caller should mark the changelog as seen.

Implementation

Future<bool?> showWhatsNewSheet(
  BuildContext context,
  List<ChangelogEntry> entries,
) {
  return showModalBottomSheet<bool>(
    context: context,
    isScrollControlled: true,
    useSafeArea: true,
    shape: const RoundedRectangleBorder(
      borderRadius: BorderRadius.vertical(top: Radius.circular(16)),
    ),
    builder: (ctx) => _WhatsNewSheet(entries: entries),
  );
}
